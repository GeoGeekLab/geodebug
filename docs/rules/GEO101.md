# GEO101 — Missing CRS

**Scope:** dataset  
**Default severity:** warning  
**Certainty:** deterministic

Reports when a dataset explicitly has no declared coordinate reference system.
It does not guess a CRS from coordinate values.

**PASS:** CRS presence is explicitly established.  
**FAIL:** CRS metadata is explicitly absent.  
**UNKNOWN:** CRS presence cannot be established.  
**NOT_APPLICABLE:** no dataset subject is available.

**Remediation:** establish the CRS from authoritative source metadata before
assigning it. Do not infer and write a CRS solely from plausible bounds.
