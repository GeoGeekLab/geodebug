# GEO501 — Buffer on angular CRS

**Scope:** operation  
**Default severity:** error  
**Certainty:** deterministic

Reports a planar buffer operation on a geographic CRS when the supplied
distance would be interpreted in angular coordinate units.

**PASS:** the input CRS is projected.  
**FAIL:** the input CRS is geographic and a distance is supplied.  
**UNKNOWN:** CRS semantics or the distance parameter is unavailable.  
**NOT_APPLICABLE:** the operation is not `buffer`.

GeoDebug recommends projecting to an appropriate linear CRS before a metric
buffer; it does not select that CRS automatically.
