# GEO201 — Invalid geometry

**Scope:** dataset  
**Default severity:** error  
**Certainty:** deterministic  
**Cost:** full scan

Reports vector geometries that fail the geometry engine's validity predicate.
File-based checks require deep inspection when validity is not available from
metadata.

**PASS:** the scanned dataset contains no invalid geometries.  
**FAIL:** one or more invalid geometries are present.  
**UNKNOWN:** geometry validity has not been scanned.  
**NOT_APPLICABLE:** the subject is not vector data.

Automatic geometry repair is intentionally not performed because repair can
change geometry type and topology.
