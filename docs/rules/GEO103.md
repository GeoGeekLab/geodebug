# GEO103 — Geographic coordinate out of range

**Scope:** dataset  
**Default severity:** error  
**Certainty:** deterministic

Checks declared geographic data for implausible angular coordinate ranges.
Latitude must remain within ±90 degrees; longitude is allowed within the
commonly encountered -360 to 360 degree domain.

**PASS:** geographic bounds are within supported angular ranges.  
**FAIL:** observed bounds exceed those ranges.  
**UNKNOWN:** finite bounds cannot be established.  
**NOT_APPLICABLE:** the CRS is not geographic.

This rule diagnoses a mismatch between declared CRS semantics and coordinates;
it does not identify the correct CRS.
