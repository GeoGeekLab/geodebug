# GEO503 — Planar distance on geographic CRS

**Scope:** operation  
**Default severity:** error  
**Certainty:** deterministic

Reports planar `distance` or `length` measurement on a geographic CRS.

**PASS:** the input CRS is projected.  
**FAIL:** the input CRS is geographic.  
**UNKNOWN:** CRS semantics cannot be established.  
**NOT_APPLICABLE:** the operation is neither `distance` nor `length`.

The rule does not prohibit explicitly geodesic measurement algorithms.
