# GEO502 — Planar area on geographic CRS

**Scope:** operation  
**Default severity:** error  
**Certainty:** deterministic

Reports planar area measurement on a geographic CRS.

**PASS:** the input CRS is projected.  
**FAIL:** the input CRS is geographic.  
**UNKNOWN:** CRS semantics cannot be established.  
**NOT_APPLICABLE:** the operation is not `area`.

The rule concerns planar coordinate-unit area. Geodesic area calculations are a
different operation contract.
