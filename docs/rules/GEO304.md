# GEO304 — NoData conflicts with valid mask

**Scope:** dataset  
**Default severity:** warning  
**Certainty:** deterministic  
**Cost:** full scan

Reports bands where pixels equal to the declared NoData value are simultaneously
marked valid by the dataset validity mask.

**PASS:** a deep scan finds no conflicts.  
**FAIL:** one or more bands contain mask/NoData conflicts.  
**UNKNOWN:** a required deep scan has not been performed.  
**NOT_APPLICABLE:** the raster has no NoData value or the subject is not raster data.

The rule does not assume that merely observing the NoData numeric value is a
semantic collision.
