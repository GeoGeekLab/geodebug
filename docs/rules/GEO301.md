# GEO301 — Invalid or singular raster transform

**Scope:** dataset  
**Default severity:** error  
**Certainty:** deterministic

Validates the six affine transform coefficients and checks that the linear
transform is invertible.

**PASS:** coefficients are finite and the determinant is non-zero.  
**FAIL:** coefficients are malformed/non-finite or the transform is singular.  
**UNKNOWN:** transform metadata is unavailable.  
**NOT_APPLICABLE:** the subject is not raster data.
