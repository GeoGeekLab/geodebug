# GEO404 — Raster grid misalignment

**Scope:** relation  
**Default severity:** warning  
**Certainty:** deterministic

Checks whether two rasters with the same CRS and resolution share the same
pixel lattice. Integer-pixel origin offsets are aligned; fractional offsets are
not.

**PASS:** grids share the pixel lattice.  
**FAIL:** a fractional-pixel offset is present.  
**UNKNOWN:** CRS/resolution is incompatible or rotation/skew prevents the
current deterministic test.  
**NOT_APPLICABLE:** the relation is not between raster grids.
